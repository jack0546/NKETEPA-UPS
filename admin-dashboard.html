👤 User Accounts — How to Create a Teacher Login

Manual 4-step process. Do this whenever you hire a new teacher.

  1. Create the staff record in Staff Management. Leave the staff number blank — it auto-generates. Note the new staff_id from Supabase → Table Editor → staff.
  2. Create the auth user in Supabase → Authentication → Users → Add user → Create new user.
    Fill in email + password and tick "Auto Confirm User". Copy the new user's UID.
  3. Link them. Run this SQL in Supabase → SQL Editor, replacing the UID and staff_id: 
    insert into user_profiles (user_id, role, staff_id)
values ('PASTE-UID-HERE', 'teacher', 2);
  4. Test. Have the teacher log in at the login page. They should land on the teacher dashboard.
⚠️ Common errors:
• duplicate key user_profiles_staff_id_key — that staff_id is already linked to another user. Use a different staff_id or update instead of insert.
• "Unable to sign in" — email not confirmed. In Auth → Users, confirm the user manually, or set email_confirmed_at = now().
• Teacher dashboard stuck on "Verifying…" — no class is assigned to them yet. Go to Academic Management → Teachers and assign them a class.
